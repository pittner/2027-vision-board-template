# Free printable 2027 vision board template

**Live page: https://pittner.github.io/2027-vision-board-template/**

One A4 sheet (also prints on US Letter) for the whole of 2027:

- 2027 in one word, and what has to be true by 31 December 2027
- four quarters, each with one picture and one proof you can check on its date (31 March, 30 June, 30 September, 31 December)
- what you leave in 2026, what you keep doing
- a first step to take before 1 January, and four review boxes

Print it straight from the browser (or Save as PDF), or download SVG / PNG (1654x2339, A4 at 200 dpi). No signup, no e-mail, no watermark.

On a phone, the free browser maker at [visionboard.bemooore.com](https://visionboard.bemooore.com/free-vision-board-maker/?utm_source=github&utm_medium=referral&utm_campaign=template_2027_readme) turns a 2027 goal into a 1080x1920 lock-screen wallpaper.

More sheets: [7 printable vision board templates](https://pittner.github.io/vision-board-templates/).

## Source

`index.html` is generated by `build.py`. The sheet itself is drawn by `sheet_2027()` in
[pittner/vision-board-templates](https://github.com/pittner/vision-board-templates), so both pages print the same file.
